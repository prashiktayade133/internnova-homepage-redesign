# InternNova Homepage Redesign

A responsive, original homepage redesign created for the InternNova web development assignment.

## Files
- `index.html` — semantic homepage structure and content
- `styles.css` — responsive UI, layout, cards, animations/hover states
- `script.js` — mobile navigation and smooth interaction helpers

## Design direction
- Modern editorial + SaaS aesthetic
- Purple accent retained as the brand cue
- Stronger hierarchy and CTA visibility
- Internship programs surfaced earlier
- Mobile-first responsive breakpoints
- Accessible semantic sections, buttons and FAQ accordions

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
Upload these files to a GitHub repository and enable GitHub Pages, or import the repository into Vercel/Netlify.

## Reference analysis
The redesign uses InternNova's public information as reference, including its internship domains, 4–6 week positioning, mission and student portal, while using a distinct visual system and original layout.
